# PHP Лендинг с авторизацией через Yandex ID и VK ID

## Описание
Лендинг страница с возможностью авторизации через Яндекс и ВКонтакте. После авторизации пользователь сохраняется в SQLite базу данных.

## Требования
- PHP 7.4 или выше
- Расширение SQLite3
- Расширение cURL
- Веб-сервер (Apache, Nginx и т.д.)

## Установка

### 1. Настройка OAuth приложений

#### Яндекс OAuth
1. Перейдите на https://oauth.yandex.ru/client/new
2. Создайте новое приложение
3. Укажите Redirect URI: `http://localhost/php-landing/callback.php?provider=yandex`
4. Выберите права доступа:
   - `login:info` - доступ к информации о пользователе
5. Скопируйте Client ID и Client Secret

#### ВКонтакте OAuth
1. Перейдите на https://vk.com/apps?act=manage
2. Создайте новое приложение типа "Сайт"
3. Укажите адрес сайта и базовый домен
4. В настройках укажите Redirect URI: `http://localhost/php-landing/callback.php?provider=vk`
5. Скопируйте API ID (Client ID) и защищённый ключ (Client Secret)

### 2. Конфигурация проекта

Откройте файлы `index.php` и `callback.php` и замените следующие значения:

```php
// Для Яндекса
$yandex_client_id = 'ВАШ_YANDEX_CLIENT_ID';
$yandex_client_secret = 'ВАШ_YANDEX_CLIENT_SECRET';

// Для ВКонтакте
$vk_client_id = 'ВАШ_VK_CLIENT_ID';
$vk_client_secret = 'ВАШ_VK_CLIENT_SECRET';
```

### 3. Настройка веб-сервера

Убедитесь, что ваш веб-сервер настроен на обработку PHP файлов и имеет доступ к папке проекта.

Пример конфигурации для Apache (.htaccess):
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /php-landing/
    DirectoryIndex index.php
</IfModule>
```

## Структура базы данных

Таблица `users`:
- `id` - уникальный идентификатор пользователя (автоинкремент)
- `provider_id` - ID пользователя в системе провайдера (Яндекс/VK)
- `provider_name` - название провайдера ('yandex' или 'vk')
- `avatar_path` - URL аватарки пользователя
- `nickname` - никнейм пользователя (изменяемый)
- `created_at` - дата регистрации

## Функционал

1. **Авторизация**
   - Вход через Яндекс ID
   - Вход через VK ID

2. **Профиль пользователя**
   - Отображение аватарки
   - Отображение никнейма
   - Возможность изменения никнейма
   - Выход из аккаунта

3. **Хранение данных**
   - Все данные сохраняются в SQLite базу данных `users.db`
   - При повторной авторизации данные обновляются

## Использование

1. Откройте страницу в браузере
2. Выберите способ авторизации (Яндекс или ВКонтакте)
3. После успешной авторизации вы будете перенаправлены обратно на сайт
4. В профиле вы можете изменить свой никнейм
5. Для выхода нажмите кнопку "Выйти"

## Безопасность

- Используется сессия PHP для хранения состояния авторизации
- Prepared statements для защиты от SQL-инъекций
- Экранирование выводимых данных через htmlspecialchars()

## Примечания

- База данных `users.db` будет создана автоматически при первом запуске
- Убедитесь, что у веб-сервера есть права на запись в папку проекта для создания БД
- Для продакшена используйте HTTPS и обновите redirect_uri в настройках OAuth приложений
